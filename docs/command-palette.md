# 命令面板与设置联动

AIDE 的命令面板是一个输入框两种模式：文件模式与命令模式。`Ctrl+P` / `Ctrl+Shift+P` 打开同一组件，初始值分别是空串与 `>`。

## 键位

| 操作 | 默认键位 | 说明 |
| --- | --- | --- |
| 快速打开文件 | `Ctrl+P` | 模糊匹配文件名；空查询优先列出最近打开的文件 |
| 显示所有命令 | `Ctrl+Shift+P` | 命令模式；输入框首字符 `>` |
| 用 AI 修改选中代码 | `Ctrl+K` | 选中代码或当前行，结果以 diff 覆盖层呈现 |
| 采纳整条补全 | `Tab` | 由 Monaco 提供，快捷键面板中只读展示 |

快速打开与命令面板共用同一个输入框：删除 `>` 会回到文件模式，不需要关闭重开。键位来自设置页的同一份注册表，改完立即生效；命令右侧的键位提示可以在设置里关掉。

## 命令范围

命令按分组连续排列，空查询时全部可见（结果上限 120 行，当前 78 条）：

- **文件**：保存当前文件/全部文件、关闭当前/其他/右侧/已保存/全部、固定标签、复制相对与绝对路径。
- **编辑器**：AI 修改、撤销重做、查找替换、转到行、格式化、注释、复制行、上下移行、选择所有出现、折叠展开、缩进。
- **视图**：资源管理器、搜索、源代码管理、左侧栏、DSH 对话栏、问题/输出/改动/调试控制台、底部面板、Markdown 大纲与源码/预览、差异内联/并排。
- **搜索**：聚焦输入框、替换、下一个/上一个结果。
- **终端**：显示/隐藏、新建、拆分当前、关闭当前。
- **源代码管理**：刷新、暂存全部、取消暂存全部、填写提交信息、抓取、拉取、推送、提交图、Git 输出。
- **AI**：解释/修复/重构/生成测试/添加注释/审查选区（只插入 DSH 输入框，不自动发送）。
- **DSH**：把选中代码添加到对话。
- **审查**：建立检查点、确认全部工作区改动。
- **语言服务**：定义、引用、重命名、文件/工作区符号、快速修复、下一个/上一个问题。
- **其它**：小恐龙、AIDE 设置、返回 DSH。

终端与 Git 的写操作由命令面板派发事件、对应面板监听后执行，保证 busy 状态、错误条、提交图与远程提示和直接点面板按钮一致。Git 的「填写提交信息」只聚焦信息框，提交仍需要用户确认消息；放弃改动只保留在面板内（破坏性操作，需要二次确认）。

## 设置项

设置页按分组组织，与命令面板直接相关的有：

- **AI 补全**：只有总开关与触发延迟；模型固定使用 DSH 当前的默认模型。
- **命令面板与改动**：最近文件条数（0–40）、是否显示键位、改动面板是否随文件变化自动刷新。
- **快捷键**：可改命令的键位；命令面板右侧的提示与这里同源。

补全与 AI 修改都没有模型路由、失败兜底或独立设置文件：模型不可用时直接在 DSH 里换模型即可。

## 管线

- 状态栏「N 个未确认」入口来自 `review.count`，文件变化后 800ms 合并刷新；宿主侧 `git status` 有 1.5 秒缓存。
- 改动面板监听文件变化自动刷新（可关），命令面板的确认/检查点通过 `dvw-review-refresh` 立即刷新，不受自动刷新开关影响。
- 检查点写入工作区 `.dsh-workbench/checkpoints.json`，回滚前自动备份当前状态。
- AI 修改结果以覆盖层显示，接受后作为一次可撤销编辑写回；期间文件被外部改动时拒绝应用并关闭预览。

## 性能

- 文件清单由宿主按工作区缓存 5 秒，客户端再缓存 5 秒；不读文件内容。
- 两万条路径下单次过滤排序约 5–10ms，排序在 `useDeferredValue` 上执行，输入不被阻塞。
- 78 条命令的空查询排序约 0.003ms，带查询约 0.04ms。
- 改动面板刷新 400ms 合并；`review.count` 命中状态缓存时约 0.003ms，冷启动一次 `git status` 在 Windows 上约 300ms。
